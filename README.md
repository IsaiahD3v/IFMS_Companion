# IFMS_Companion
# 🏛️ Portal Agregador de Editais IFMS

> **Uma plataforma centralizada para mitigação da desinformação e distribuição eficiente de comunicados acadêmicos.**

## 📌 Sobre o Projeto

Este projeto consiste em uma aplicação web desenvolvida para atuar como um agregador inteligente de editais, avisos e comunicados oficiais. O objetivo central é fornecer um ambiente onde a comunidade acadêmica possa encontrar informações pertinentes de maneira rápida, categorizada e útil para suas necessidades específicas.

O sistema foi arquitetado não apenas para resolver o problema imediato de assimetria de informação — que frequentemente afeta o engajamento de estudantes e docentes —, mas também para servir como uma infraestrutura base escalável. 

### Visão de Futuro e Escalabilidade
A arquitetura atual estabelece os alicerces para a implementação de novas *features* de alto impacto para a comunidade. O escopo futuro inclui a evolução da plataforma para uma **Central de Notificações Unificada**, abrangendo não apenas editais, mas também eventos, processos seletivos e oportunidades acadêmicas.

---

## 🎓 Contexto Acadêmico e Gerencial

O projeto foi concebido inicialmente como escopo prático e avaliativo para a Unidade Curricular de **Gerenciamento de Projetos**. A iniciativa envolveu a seleção de uma ferramenta de gestão, sua dissecação técnica e a aplicação de boas práticas de coordenação de equipes, culminando no desenvolvimento deste software sob a minha coordenação como Gerente de Projetos.

Além do cumprimento do rigor acadêmico, este repositório nasce com um direcionamento corporativo. O desenvolvimento, a manutenção e a expansão desta infraestrutura estão alinhados com o propósito de serem integrados ao guarda-chuva de uma **Empresa Júnior (EJ)** de desenvolvimento de software no instituto. Esta estratégia visa proporcionar um ambiente real de ganho de experiência de mercado, gestão de ciclo de vida de produto e operação profissional para os membros envolvidos.

## 🤝 Regras de Contribuição e Manutenção

A manutenção e evolução contínua deste software são conduzidas de forma colaborativa por estudantes. No entanto, para garantir o controle de qualidade, a segurança e o alinhamento com os objetivos da futura EJ, **a contribuição aberta possui restrições estritas:**

1. **Exclusividade Institucional:** A participação no desenvolvimento é vedada ao público externo. Apenas indivíduos ativamente vinculados ao Instituto Federal de Mato Grosso do Sul (IFMS) podem contribuir.
2. **Aprovação Prévia:** O envio de *Pull Requests* ou a solicitação de acesso ao repositório estão sujeitos à análise e aprovação direta dos responsáveis atuais pelo projeto (Mantenedores / Gerência do Projeto).
3. **Padrão de Qualidade:** Todas as contribuições devem seguir as diretrizes de código estabelecidas e passar por revisão por pares antes de serem integradas à *branch* principal.

Se você é aluno do instituto e deseja fazer parte deste desenvolvimento, entre em contato com a equipe de gestão para solicitar permissão de colaboração.
